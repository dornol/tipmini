VS Code를 자주 사용한다면 마우스보다 단축키를 익혀두는 것만으로도 작업 속도가 꽤 빨라집니다.

## 파일과 창 이동

| 단축키 | 기능 |
| --- | --- |
| `Ctrl/Cmd + P` | 파일 이름으로 빠르게 열기 |
| `Ctrl/Cmd + Shift + P` | 명령 팔레트 열기 |
| `Ctrl/Cmd + B` | 사이드바 열기/닫기 |
| `Ctrl/Cmd + W` | 현재 편집기 닫기 |

## 코드 편집

| 단축키 | 기능 |
| --- | --- |
| `Alt/Option + ↑/↓` | 현재 줄 위/아래로 이동 |
| `Shift + Alt/Option + ↑/↓` | 현재 줄 복사 |
| `Shift + Alt/Option + F` | 문서 전체 포맷팅 |
| `Ctrl/Cmd + D` | 같은 단어를 다음 선택 영역에 추가 |
| `Ctrl/Cmd + /` | 주석 처리/해제 |

처음에는 `Ctrl/Cmd + P`, 명령 팔레트, 줄 이동 단축키 세 가지만 익혀도 충분합니다. 운영체제에 따라 `Ctrl`은 `Cmd`, `Alt`는 `Option`으로 바꿔 사용하면 됩니다.
